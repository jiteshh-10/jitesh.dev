# Jitesh Sen Portfolio

Illustrated, responsive developer portfolio built with Next.js, TypeScript, Tailwind CSS, React SVG, and GSAP.

## Development

```bash
pnpm install
pnpm dev
```

The initial milestone includes the animated Hero, EcoDrop transition, modular content data, and future section shells. Profile facts that were not supplied are intentionally marked `TODO` in `data/portfolio.ts`.

See `ARCHITECTURE.md`, `ANIMATION_GUIDE.md`, `ILLUSTRATION_GUIDE.md`, and `RESPONSIVE_GUIDE.md` for implementation conventions.
